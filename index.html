部署步骤

  1. 1
    打开 Files

    进入 ACLClouds Bot 的文件管理器。

  2. 2
    创建 config.env

    Create File → 名称填 config → 类型选 Env (.env)，粘贴配置。

  3. 3
    设置 Startup Command

    进入 Startup，粘贴上方生成的固定 bootstrap 命令；以后无需修改版本 URL。

  4. 4
    Restart

    等待 Console 显示 Server marked as running 和已启用服务状态；启用代理时会输出 VLESS 链接。

  5. 5
    Console 查询

    启用代理后输入 2 找回链接；启用自动延期后输入 7 查看最近检查结果。
